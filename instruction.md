# Инструкция: Как создать локальную копию удаленного репозитория (клонирование)

Клонирование — это процесс создания полной локальной копии удаленного репозитория на вашем компьютере. Это позволяет работать с файлами проекта, вносить изменения и затем отправлять их обратно на GitHub.

## Шаги

1.  **Найдите URL репозитория на GitHub.**
    *   Откройте страницу нужного репозитория на GitHub.
    *   Нажмите на зеленую кнопку **Code**.
    *   Скопируйте URL. Для работы через SSH выберите вкладку **SSH** и скопируйте ссылку (она начинается с `git@github.com:...`).

2.  **Откройте терминал (Git Bash) на вашем компьютере.**

3.  **Перейдите в директорию, где вы хотите разместить проект.**
    *   Используйте команду `cd`, чтобы перейти в нужную папку. Например:
        ```bash
        cd /c/Users/Ваше_Имя/Projects
